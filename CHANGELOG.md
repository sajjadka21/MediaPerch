# Changelog

## 0.9.0 — 2026-11-13

First public release of **MediaPerch**. Earlier version numbers belonged to internal test builds.

- Persian and English interfaces with warm and dark themes.
- A local film, series, anime and file library with poster artwork, seasons and episodes.
- Online metadata with a visual result picker for ambiguous titles.
- Smart Organize directly from a title, category, collection or the sidebar, with a preview and copy by default.
- Named title/season folders, linked subtitles, Explorer folder artwork and conditional Undo.
- MediaPerch desktop and Start menu shortcuts with an explicit dedicated icon.
- Resumable verified updates and a frozen-app startup check before packaging.
- English and Persian product documentation with original demo-library screenshots.
- Linux x86_64 packages: AppImage, Debian, RPM and portable tar.gz (glibc 2.39+).
- Native Linux scanning, safe file operations, desktop integration and secure desktop-keyring storage.
